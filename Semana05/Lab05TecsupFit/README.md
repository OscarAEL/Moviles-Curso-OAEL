# TECSUP Fit

Aplicación móvil para la reserva de clases de gimnasio desarrollada con Kotlin y Jetpack Compose.

## Requerimientos funcionales

### RF01 - Listar clases disponibles
La aplicación debe mostrar una lista de clases disponibles con su nombre y horario. Además, permitirá filtrar las clases mediante las opciones "Hoy" y "Esta semana".

### RF02 - Ver detalle de la clase
El usuario podrá seleccionar una clase de la lista y visualizar su detalle, incluyendo nombre, horario, duración, descripción y cupos disponibles.

### RF03 - Reservar cupo
El usuario podrá reservar un cupo para la clase seleccionada, eligiendo un horario disponible y posteriormente visualizar una confirmación de la reserva.

### RF04 - Ver reservas y perfil
El usuario podrá acceder a la sección Reservas para visualizar las clases reservadas con su estado, y también consultar su Perfil con datos y estadísticas simples de asistencia.
