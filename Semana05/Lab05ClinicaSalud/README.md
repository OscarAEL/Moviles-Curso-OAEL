# Clínica Salud+

Aplicación móvil para la reserva de citas médicas desarrollada con Kotlin y Jetpack Compose.

## Requerimientos funcionales

### RF01 - Listar médicos disponibles
La aplicación debe mostrar una lista de médicos disponibles con su nombre, especialidad y calificación. Además, permitirá filtrar los médicos por especialidad.

### RF02 - Ver perfil del médico
El usuario podrá seleccionar un médico de la lista y visualizar su perfil con información como nombre, especialidad, experiencia, calificación y descripción.

### RF03 - Agendar cita
El usuario podrá agendar una cita con el médico seleccionado, eligiendo una fecha y una hora disponibles. Luego podrá confirmar la cita y visualizar un resumen.

### RF04 - Ver mis citas
El usuario podrá acceder a la sección Mis citas y visualizar las citas registradas mostrando el médico, fecha, hora y estado.
